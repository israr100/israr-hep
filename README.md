# Hi, I'm Israr 👋

**Experimental physicist (CMS @ CERN) transitioning into data science, ML engineering, and quantitative research.**

I spend my days extracting small signals from enormous, noisy datasets — statistical inference on petabyte-scale collision data, building ML classifiers to separate signal from background, and running large distributed compute jobs to do it. I'm now bringing that toolkit to industry.

---

## What I work on

- **Statistical modeling & inference** — hypothesis testing, maximum-likelihood fits, systematic uncertainty estimation, and effective-field-theory parameter scans on real experimental data.
- **Machine learning** — gradient-boosted and neural-network classifiers (XGBoost, PyTorch) for high-dimensional event classification.
- **Large-scale data engineering** — columnar processing of multi-terabyte datasets, distributed batch computing (HTCondor), and remote data access (XRootD/EOS).
- **From physics to product** — translating research-grade analysis into reproducible, well-documented pipelines.
